## 2. Descripción Completa para Perfil de LinkedIn

**Voluntario - Desarrollo Web | Hogar Aleluya (ONG)**

**Proyecto**: Modernización y Optimización del Sitio Web Institucional

Como parte de mi voluntariado técnico (Etapa 2: Mejora y Modernización), lideré la refactorización completa del sitio web de la ONG Hogar Aleluya, enfocándome en seguridad, automatización y modernización tecnológica.

**Principales Logros**:

-   **Pipeline de CI/CD**: Implementé GitHub Actions para automatizar el proceso de build, validación y despliegue a Firebase Hosting, reduciendo el tiempo de deployment en un 80% y eliminando la necesidad de intervención manual.
-   **Seguridad**: Identifiqué y solucioné un problema crítico de seguridad al migrar credenciales hardcodeadas a variables de entorno gestionadas con GitHub Secrets.
-   **Modernización Tecnológica**: Actualicé el SDK de Firebase de la versión legacy (v7) a la v9+ (modular), eliminé dependencias obsoletas (jQuery) y refactoricé el código a ES6+ modules.
-   **Proceso de Build**: Desarrollé scripts de automatización con Node.js para la minificación de CSS/JS (Terser, PostCSS) y la optimización de imágenes (Sharp), preparando los assets para un rendimiento óptimo en producción.
-   **Arquitectura**: Reorganicé la estructura del proyecto (`src/` -> `dist/`), implementé `package.json` para la gestión de dependencias y establecí mejores prácticas de organización de código.
-   **Documentación**: Creé un análisis técnico exhaustivo, documentación de configuración y guías de implementación para facilitar la colaboración y el mantenimiento futuro.

**Impacto**: El proyecto mejoró significativamente la seguridad, automatización, mantenibilidad y escalabilidad del sitio web, estableciendo una base técnica sólida para el crecimiento futuro de la plataforma de la ONG.

**Tecnologías**: HTML5, CSS3, JavaScript (ES6+), Firebase v9+, Node.js, GitHub Actions, CI/CD, Build Automation, PostCSS, Terser, Sharp.
